CLAUDE.md



Project

Project name: Çevre Dostu Yaşam Asistanı



This project is a Turkish-language application designed to encourage environmentally friendly daily habits.



Technologies

\- HTML

\- CSS

\- JavaScript

\- Local browser storage (localStorage)



Main Features

\- Waste separation guidance

\- Water and energy saving suggestions

\- Daily environmental tasks and progress tracking

\- Demo environmental assistant



Development Rules

1\. Preserve the existing design and Turkish interface.

2\. Keep the application simple and suitable for beginner users.

3\. Do not remove existing working features.

4\. Use clear and understandable HTML, CSS, and JavaScript.

5\. Test changes before considering them complete.

6\. Explain proposed changes before editing project files.

7\. Do not modify files without the user's approval.

8\. Do not add unnecessary libraries or dependencies.

9\. Never place passwords, API keys, or private tokens in source code.

10\. Keep the application usable without an internet connection.



AI Assistant Limitations

The assistant feature currently uses demo keyword-based responses. Do not describe it as a real AI integration unless an actual AI service is connected and tested.



Instructions for AI Tools

Before making changes:

\- Inspect the relevant files.

\- Explain the problem and proposed solution.

\- List the files that will be changed.

\- Wait for user approval.



After making approved changes:

\- Explain what changed.

\- List the tests performed.

\- Report any remaining limitations.
